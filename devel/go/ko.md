## Install

:::::{tab-set}
:::: {tab-item} Ubuntu
:sync: ubuntu

```console
$ curl -sLO https://github.com/ko-build/ko/releases/download/v0.19.1/ko_0.19.1_Linux_x86_64.tar.gz
$ tar -xzf ko_0.19.1_Linux_x86_64.tar.gz
$ sudo install ko /usr/local/bin/
```

```console
$ ko version
0.19.1
```
